# Simulação de atendimento com disparo de clientes.

## Sobre o Projeto

Este projeto tem como objetivo aplicar e consolidar conhecimentos em **modelagem de dados**, **manipulação de dados** e **automações via Web Scraping**.

O fluxo abrange desde a coleta automatizada de informações na web até a estruturação, transformação e armazenamento eficiente dos dados para análise.

---

## Tecnologias Utilizadas

* **Linguagem:** Python, PHP
* **Web Scraping & Automação:** Selenium 
* **Armazenamento / Modelagem:** SQL (PostegreSQL)

---

## Objetivos e Funcionalidades

* **Automação Web:** Envio automatizado de dados a partir de elementos web.
* **Modelagem de Dados:** Estruturação de esquemas e relacionamentos de dados.

---


## Como Executar

1. **Clonar o repositório:**
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git

```

2. **Instalar as dependências:**
```bash
pip install -r requirements.txt

```

3. **Executar a aplicação:**
```bash
python disparar_clientes.py

```
